# Retail Sales Analysis using Excel

## 📌 Project Overview
This project analyzes retail sales data using Microsoft Excel. Pivot Tables are used to identify sales trends, customer behavior, and regional performance.

## 📊 Key Analysis Performed
- Sales by Region and Category
- Sales by Shipping Mode
- Sales by Customer Segment
- State-wise Sales Analysis
- Product Category Performance

## 🛠 Tools Used
- Microsoft Excel
- Pivot Tables
- Charts & Dashboard

## 📈 Key Insights
- Technology category contributes the highest sales.
- East region is the top-performing region.
- Consumer segment generates maximum revenue.
- Second Class shipping mode is most preferred.

## 📁 Project Files
- `retail.xlsx` → Raw data, pivot tables, and dashboard
- `screenshots/` → Dashboard and pivot table images

## 🚀 Outcome
This project demonstrates practical skills in data cleaning, pivot table analysis, and business insight generation using Excel.
